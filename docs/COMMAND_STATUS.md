# 命令・機能の実装状況

`src/parser.cpp` / `src/lexer.cpp` とホスト単体テスト（`BUILD_TESTS=ON`）の整理に基づく一覧です。実機（Pico）では HAL のスタブ／未リンク箇所により挙動が異なる場合があります。

開発フェーズ全体との対応は **[PHASE_RUNTIME.md](./PHASE_RUNTIME.md)**、Hu-BASIC との差分は **[RUNTIME_GAPS.md](./RUNTIME_GAPS.md)** を参照してください。

## 凡例

| 記号 | 意味 |
| :--- | :--- |
| **実装** | 実行パスがあり、ホストテストまたは実機で主用途が動く |
| **部分** | 認識・分岐はあるがスタブ・簡易実装、または I/O がホスト依存 |
| **未実装** | 字句は認識するが実行時に「未実装」通知でスキップされる（`execute_not_implemented`） |

## システム・プログラム管理

| 命令 | 状態 | メモ |
| :--- | :--- | :--- |
| `NEW` / `CLEAR` | 実装 | プログラム・変数の消去 |
| `REM` / `'` | 実装 | コメント。本文を保持し `LIST` に残る |
| `LIST` | 実装 | プログラム一覧。範囲指定可（`LIST 100-200` / `LIST 100` / 片側開放） |
| `RENUM` | 実装 | 行番号振り直し（既定 10,10）。GOTO/GOSUB/THEN/ELSE/ON の飛び先も書き換え |
| `DELETE` | 実装 | 行範囲の削除（`DELETE 100-200` / 片側開放も可） |
| `CONT` | 実装 | STOP / Ctrl-C の続きから再開（文単位）。プログラム編集で無効化 |
| `TRON` / `TROFF` | 実装 | 実行行トレース `[N]` の開始／停止 |
| `AUTO` | 実装 | 行番号自動生成（`AUTO [開始 [, 刻み]]`）。既定 10 / 10。空行入力または Ctrl-C で終了。対話入力の `repl.cpp` が処理 |
| `RUN` | 実装 | 行番号昇順で実行。開始時に変数・配列を初期化。実行中は **Ctrl-C** で中断（`Break in N`） |
| `SAVE` / `LOAD` | 実装 | 実機は FatFS + MicroSD、ホストは `fopen` |
| `FILES` | 実装 | 実機は SD ルート、ホストは `opendir` カレント |
| `KILL` / `NAME` | 実装 | 同上（`hal_sdcard` 経由） |
| 画面保存（Ctrl-P） | 実装 | LCD を 24bit BMP で SD へ（`SCR00.BMP`〜）。実行中も可。`screenshot.cpp` は HAL 依存のみでホストテスト可能 |
| `OPEN` / `CLOSE` | 実装 | シーケンシャルファイル。`OPEN f$ FOR INPUT\|OUTPUT\|APPEND AS #n`（#1〜#4） |
| `PRINT #` / `INPUT #` | 実装 | 値を "," 区切りの行で往復。`EOF(n)` で終端判定。END/RUN/NEW で自動 CLOSE |

## サウンド・その他ハード

| 命令 | 状態 | メモ |
| :--- | :--- | :--- |
| `BEEP` | 実装 | 実機は I2S DAC で発音（880Hz / 200ms）、ホストはログ |
| `MUSIC` / `PLAY` | 実装 | 同一 `execute_music`（MML サブセット）。カンマ区切りで最大 3 声の和音。**非同期再生**（Ctrl-C / `NEW` で停止） |
| `SOUND` | 実装 | `SOUND reg, data`（PSG レジスタ）。トーン3ch・ノイズ・音量・エンベロープ |
| `WAIT` | 実装 | |
| `GPIO` | 部分 | Pico 定義時は実 GPIO、ホストはモック |
| `TOUCH(...)` 関数 | 実装 | 実機は CST328（I2C）、ホストはモック値 |
| `BATTERY(...)` 関数 | 実装 | 0=mV / 1=残量% / 2=接続推定 / 3=USB 給電（CDC 接続で代用）。`BAT_ADC`(GPIO27, ADC1) を 200K:100K で分圧。残量は直線近似、有無は電圧からの推定 |
| `POKE` / `PEEK(...)` | 実装 | 論理メモリ（64KB `logical_memory`）への 1 バイト読み書き。0-65535、値は 8bit。物理メモリマップではない |

## 字句のみ・実行時未実装

現在、字句は受理するが未実装通知（`execute_not_implemented`）で終わる命令は **ありません**。

`INIT` / `NEWON` は互換のための空実装（引数を受理して何もしない。元の X1 Hu-BASIC のメモリ領域予約に対応する概念がこの実装には無いため）。
