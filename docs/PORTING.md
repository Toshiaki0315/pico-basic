# 別の RP2350 ボードへの移植

## 現状

ハードウェアに触るコードは **`src/hal_*.cpp` と `src/main.cpp` だけ**です。
インタプリタ本体（約 5,000 行）は一切ハードウェアを参照せず、ホスト PC 上で
単体テストできます。移植で一番コストがかかる「依存の切り離し」は済んでいます。

さらに、**タッチ・IMU・RTC は起動時に検出して無ければ機能を無効化**します。

```
[TP] CST328 not found (TOUCH() will always return 0)
[IMU] QMI8658 not found
[RTC] PCF85063A not found
```

これらを積んでいないボードでも、そのまま起動して BASIC は動きます。

## 手順

### 1. 配線を差し替える（`src/board_config.h`）

ピン番号・バス・画面サイズ・分圧比は **`src/board_config.h` に集約**してあります。
同じ構成のチップを別のピンに繋いだボードなら、**このファイルだけ**で対応できます。

チップ固有のレジスタ定義（CST328 / QMI8658 / PCF85063A のレジスタ番号やビット位置）は
各ドライバに残してあります。チップが変わればドライバごと差し替えることになり、
配線表に混ぜても使い回せないためです。

### 2. 構成が違う部分を差し替える

| 部分 | 現状 | 別ボードで必要になること |
| :--- | :--- | :--- |
| **LCD** | ST7789V（SPI） | 別コントローラなら初期化列の差し替え（`hal_display.cpp`） |
| **MicroSD** | SDIO 固定 | SPI 接続なら `src/hw_config.c` の差し替え（ライブラリは両対応） |
| **サウンド** | I2S + PCM5101A | コーデックが無いボードは PWM 音声への置き換え（`hal_sound.cpp`） |
| **タッチ / IMU / RTC** | CST328 / QMI8658 / PCF85063A | **無ければ何もしなくてよい**（自動で無効化される） |
| **バッテリ** | 200K:100K の分圧 | 分圧比が違えば `BOARD_BAT_DIVIDER` を変更 |

SDIO 固定の理由（この基板では SPI の配線が成立しない）は `src/hw_config.c` に書いてあります。

### 3. 画面サイズが違う場合

`BOARD_LCD_WIDTH` / `BOARD_LCD_HEIGHT` を変えれば、テキストの桁数・行数は自動で追従します
（フォントは 8×8 固定）。インタプリタ側も画面サイズを直書きせず
`hal_display_get_info()` から取得しています。

ただし **`WIDTH` 命令は 40×30 のみ受け付ける**実装なので、別解像度にする場合は
`execute_width` の判定も合わせてください。

## 注意点（この基板で実際に踏んだもの）

移植先でも同じ問題に当たる可能性があるものです。

* **シリアル出力は `putchar` / `printf` / `puts` を使うこと。** Pico SDK が USB CDC に
  繋いでいるのはこの 3 つ（と `getchar`）だけで、**`fwrite` は届きません**。
* **内蔵プルダウンは効かないことがある**（erratum **RP2350-E9**）。入力ピンがリーク電流で
  2.1V 付近に張り付きます。`hal_gpio.cpp` に回避策を入れてあります。
* **I2C アドレスは回路図を鵜呑みにしない。** この基板の IMU は図では 0x6A に見えましたが、
  実機は **0x6B** でした。`hal_imu.cpp` は両方を試す作りにしてあります。
* **ADC の平均は小数のまま扱うこと。** 整数で割ると分解能が 1 サンプルのときと変わりません。
* **電池運用のボードは電源ラッチの保持が要ることがある。** この基板は `BAT_EN`(GPIO26) を起動直後に High にしないと、USB を抜いた瞬間に電源が落ちます。表示の初期化より前に立てる必要があります（スプラッシュの待ち時間があるため）。

## 確認

移植後は **[DEVICE_CHECKLIST.md](./DEVICE_CHECKLIST.md)** を上から実施してください。
搭載していない周辺デバイスの章（C＝タッチ、I＝バッテリ、K＝IMU、L＝RTC）は飛ばせます。
