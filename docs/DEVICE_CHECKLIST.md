# 実機手動テストチェックリスト（Waveshare RP2350-Touch-LCD-2.8 想定）

ホスト単体テストではカバーできない、USB・液晶・SD・タッチ・音声などの確認用です。リリース前やハード変更後に実施することを推奨します。

**準備:** `pico_basic.uf2` を書き込み済みのボード、データ対応 USB ケーブル、シリアルターミナル（VS Code Pico Serial Monitor や `screen` / `minicom` 等）。

---

|:-:|:---|:---|:---|:---:|
| A1 | 起動メッセージ | 電源投入または USB 接続後、シリアルを開く | `pico-basic v2.0` および `Ready` が表示される | [x] |

| # | 確認内容 | 手順 | 期待結果 | 合否 |

## E. MicroSD（`SAVE` / `LOAD` / `FILES`）

| # | 確認内容 | 手順 | 期待結果 | 合否 |
|:-:|:---|:---|:---|:---:|
| E0 | マウント | FAT32 でフォーマットしたカードを挿して電源投入 | シリアルに `[SD] Card not mounted` が**出ない** | [x] |
| E1 | 一覧 | カード挿入後 `FILES` | ファイル名が表示される | [x] |
| E2 | 保存・読込 | 行番号で短いプログラムを登録し `SAVE "TEST.BAS"` → `NEW` → `LOAD "TEST.BAS"` → `LIST` | 内容が復元される | [x] |
| E3 | ドライブ指定 | `SAVE "0:TEST2.BAS"` → `FILES` | `0:` 付きでも保存でき、一覧に出る | [x] |
| E4 | 削除・改名 | `NAME "TEST2.BAS" AS "TEST3.BAS"` → `FILES` → `KILL "TEST3.BAS"` → `FILES` | 改名・削除が一覧に反映される | [x] |
| E5 | カード無し | カードを抜いた状態で `FILES` | ハングやリセットをせず、エラー表示で REPL に戻る | [x] |
| E6 | 後挿し | カード無しで起動 → カードを挿して `FILES` | 再起動なしで一覧が表示される（遅延マウント） | [x] |
| E7 | サウンドとの併用 | `SAVE` 実行中・直後に `PLAY "CDE"` | 音が正常に鳴る（SD の SDIO と競合しない） | [x] |
| E8 | 抜き差し後の書き込み | カードを抜いて挿し直し `SAVE "HOT.BAS"` → `FILES` | 保存でき、`SDIO: Timed out waiting for response` 等のエラーが**出ない** | [x] |
| E9 | カード入れ替え | 別のカードに差し替えて `FILES` → `SAVE` | 差し替え後のカードの内容が正しく見え、書き込みも成功する | [x] |

> **カード検出について:** 本ボードには**カード検出用の GPIO がありません**（TF ソケットの CD 端子は GPIO に接続されていない）。そのため抜き差しはソフト側で検出するしかなく、`hal_sdcard.cpp` はファイル操作のたびに CMD13 でカードの応答を確認し、応答が無ければ再マウントします。E8 / E9 はこの仕組みの検証項目です。

※ カードは **FAT32 または exFAT** でフォーマットしてください。
