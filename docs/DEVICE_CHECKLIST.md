# 実機手動テストチェックリスト（Waveshare RP2350-Touch-LCD-2.8 想定）

ホスト単体テストではカバーできない、USB・液晶・SD・タッチ・音声などの確認用です。リリース前やハード変更後に実施することを推奨します。

**準備:** `pico_basic.uf2` を書き込み済みのボード、データ対応 USB ケーブル、シリアルターミナル（VS Code Pico Serial Monitor や `screen` / `minicom` 等）。

> **カード検出について:** 本ボードには**カード検出用の GPIO がありません**（TF ソケットの CD 端子は GPIO に接続されていない）。そのため抜き差しはソフト側で検出するしかなく、`hal_sdcard.cpp` はファイル操作のたびに CMD13 でカードの応答を確認し、応答が無ければ再マウントします。E8 / E9 はこの仕組みの検証項目です。

※ カードは **FAT32 または exFAT** でフォーマットしてください。

### F-G. GET@ / PUT@（画像の取り込みと描画）

| # | 確認内容 | 手順 | 期待結果 | 合否 |
|:-:|:---|:---|:---|:---:|
| G1 | 取り込みと描画 | `10 DIM A(1000)` / `20 CIRCLE (40,40),12,14` / `30 GET@ (28,28)-(52,52), A` / `40 PUT@ (200,150), A` → `RUN` | 右下に同じ円が複写される | [x] |
| G2 | 配列不足の検出 | `10 DIM B(10)` / `20 GET@ (0,0)-(60,60), B` → `RUN` | `Array too small for image` が表示され、ハングしない | [x] |
| G3 | 画像サイズの上限 | `DIM C(1500)` → `GET@ (0,0)-(60,60), C` | `Array too small for image` が出る（60×60=3600 画素は入らない） | [x] |
| G4 | 繰り返し実行 | G1 のプログラムを `RUN` → もう一度 `RUN` | 2 回目も同じ結果。`Out of Memory: Array Heap Full` が出ない | [x] |
| G5 | 再 DIM の拒否 | `DIM D(10)` → もう一度 `DIM D(10)` | `Duplicate definition` が表示される（`CLEAR` か `RUN` でやり直せる） | [x] |
| G6 | PUT@ XOR で消去 | `10 CLS` / `20 DIM A(500)` / `30 CIRCLE (10,10),8,15` / `40 GET@ (0,0)-(20,20),A` / `50 PUT@ (150,100),A,3` / `60 WAIT 1000` / `70 PUT@ (150,100),A,3` → `RUN` | 中央に円が1秒出て消える。**左上の円は残ったまま**（XOR で 2 回置くと消える） | [x] |
| G7 | PUT@ 拡大 | G6 に続けて `PUT@ (100,100)-(180,180), A` | 左上の小さな円が大きく引き伸ばされて中央付近に描かれる | [x] |
| G8 | PUT@ 論理演算 | `10 CLS` / `20 LINE (100,100)-(180,140),12,BF` の上に、G6 の A を `PUT@ (120,110), A, 1`（OR）や `, 2`（AND）で描く | 背景の矩形と重なった結果になる（単純上書きではない） | [x] |

> **`RUN` は画面をクリアしません**（変数・配列は初期化されます）。グラフィックのプログラムは先頭に `CLS` を入れると、前の表示と重ならず分かりやすくなります。

> **取り込める画像の大きさ:** 配列ヒープは 12,288 バイト（1,536 要素）で、`GET@` は先頭 2 要素を幅・高さに使います。
> つまり **最大 1,534 画素（正方形なら 39×39 程度）** までです。それを超える `DIM` は `Out of Memory: Array Heap Full`、
> 配列が小さすぎる `GET@` は `Array too small for image` になります。
>
> **必要な配列サイズ:** `GET@ (0,0)-(N,N)` は `(N+1)×(N+1)` 画素。`DIM A(M)` は `M+1` 要素なので、
> **`M+1 ≥ (N+1)×(N+1) + 2`** を満たすこと（幅・高さで 2 要素消費）。
> 例: `GET@ (0,0)-(20,20)` は 21×21=441 画素 → 443 要素必要 → `DIM A(442)` 以上。
